# Pitch Velocity Analyzer (motion-analysis-v2)

投球フォームの動画をブラウザ上で解析し、球速に相関するバイオメカニクス指標を自動抽出する個人開発アプリ。
ポーズ推定・指標算出・保存はすべてブラウザ内で完結し、動画やランドマークを外部に送信しない。

> **Note:** 開発中のプロジェクト。マイルストーン M0–M5(ポーズ推定〜セッション保存・トレンド)まで実装済みで、
> M6(LLM コーチング)以降は未着手。指標の検証状況は「[検証状況](#検証状況)」を参照。

- 仕様・設計方針: [CLAUDE.md](./CLAUDE.md)
- 進捗・作業ログ: [PLAN.md](./PLAN.md)

## 機能

### ポーズ推定と動画パイプライン

- MediaPipe PoseLandmarker(heavy モデル、VIDEO モード)を Web Worker 上で実行し、メインスレッドをブロックしない
- 動画を 30fps でサンプリングしてフレームごとに推論(進捗バー付き)。解析範囲(開始・終了秒)を指定できる
- `<video>` に Canvas を重ねて骨格を描画。再生・シーク・コマ送りに追従し、低信頼のランドマークは淡色で表示する

### イベント検出

- フットプラント(前足接地)とリリースを状態機械で自動検出し、各フレームへジャンプできる
- 利き腕を自動判定(手首速度ピーク近傍で肘が伸展する腕を投球腕とみなす)。右投げ・左投げの手動指定も可

### 指標算出

身長(cm)の入力から px→m 換算係数を求め(直立フレームを自動選定、肩幅で妥当性チェック)、次の7指標を算出する。

| 指標 | 内容 |
|---|---|
| ストライド長比 | フットプラント時の両足首の水平距離 ÷ 身長 |
| 接地時 / リリース時の前膝角度 | 股関節–膝–足首の角度 |
| 前膝伸展量 | リリース時 − 接地時の前膝角度 |
| 体幹前傾角 | リリース時の肩中点–股関節中点の垂直からの傾き |
| リリース時肘角度 | 肩–肘–手首の角度 |
| 手首ピーク速度 | リリース近傍の投球腕手首の合成速度(m/s) |

膝・肘角度の時系列グラフには、接地・リリースの位置を縦線で表示する。

### 入力データ品質ガード

推定が破綻した動画から、もっともらしいが根拠のない数値を出さないための仕組み。次の条件で警告し、error の場合は指標の表示と保存を止める(骨格と角度グラフは診断用に残す)。

- 主要ランドマークの欠損率(visibility < 0.5 のフレームが 30% 超で error)
- 骨格が1フレームだけ飛ぶグリッチ(イベントフレーム上なら error、それ以外は warn)
- 接地→リリースの間隔が短すぎる(warn)

### セッション保存とトレンド

- 解析結果の指標と、実測球速(スピードガン、任意)・メモを IndexedDB に保存する。動画とランドマークは保存しない
- 指標を選んで日付ごとの推移を折れ線で表示し、実測球速を右軸に重ねて描く。セッションの削除も可

### 検証状況

指標の計算ロジックは合成データの単体テストで検証しているが、実動画での検証は指標によって差がある。

- 脚側(フットプラント・ストライド長比・接地時前膝角度): 実動画で目視と ±2 フレーム以内で一致することを確認し、回帰テスト(ゴールデンテスト)で固定している
- リリース側(リリース時の前膝角度・前膝伸展量・体幹前傾角・肘角度): 撮影プロトコルに沿った検証用動画がまだなく、実動画では未検証
- 手首ピーク速度: スロー再生の動画では実時間の速度が出ないため、通常速度の動画での検証が必要で、未検証

## セットアップ

### 必要環境

- Node.js 20+
- モダンブラウザ(Chrome / Edge 最新版を推奨)
- 初回起動時のネットワーク接続。MediaPipe の wasm とモデルを CDN から取得するため(動画は送信しない)

### 起動

```bash
npm install
npm run dev
```

http://localhost:5173 を開き、身長と利き腕を設定してから動画を選択する。

### テスト

```bash
npm test          # vitest
npm run lint      # tsc --noEmit
```

## 撮影プロトコル

解析精度は撮影条件に依存する。次の条件を満たす動画を使う。

- 側面固定アングルで撮る。右投げは三塁側、左投げは一塁側。カメラは三脚で固定する
  - これは投球腕側から撮ることを意味する(本塁を向いた右投手の右腕は三塁側にある)
  - 反対側(グラブ側)から撮ってはいけない。リリース〜フォロースルーで投球腕が体幹の陰に隠れ、MediaPipe が存在しない位置にランドマークを推定する。その結果、リリース検出・肘角度・手首速度が壊れる
  - 脚側の指標(フットプラント・ストライド長・前膝角度)はどちら側から撮っても安定する
- 投手の全身(頭〜足元)が常にフレーム内に収まる
- 背景に支柱・ネットなど、投手と重なる構造物を入れない
- モーションブラーを抑えるため、明るい場所で撮る。最低 30fps(アプリは現状 30fps でサンプリングする)
- 1動画1投球(ワインドアップ前〜フォロースルーまで)。長い動画は解析範囲を指定する

> 撮影条件を満たさない動画は、品質ガードが検知して指標を出さずに警告する。
